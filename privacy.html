Politique de confidentialité

Dernière mise à jour : Juin 2026

1. Collecte des informations

Betix collecte les informations suivantes : votre nom d'utilisateur Pi Network, votre adresse de portefeuille Pi, les événements que vous créez, les tickets que vous achetez. Nous ne collectons pas d'informations confidentielles.

2. Utilisation des informations

Vos informations sont utilisées pour : créer et gérer des événements, traiter vos achats de billets, vous envoyer des confirmations, améliorer nos services.

3. Stockage des données

Vos données sont stockées localement sur votre appareil et sur nos serveurs sécurisés. Les transactions sont enregistrées sur la blockchain Pi Network.

4. Partage des informations

Nous ne vendons pas vos données personnelles. Vos informations sont partagées uniquement avec Pi Network pour les paiements et avec les organisateurs d'événements pour la validation des billets.

5. Vos droits

Vous pouvez accéder à vos données, les modifier ou les supprimer via votre profil Betix. Vous pouvez également nous contacter pour toute question.

6. Sécurité

Nous utilisons la technologie blockchain Pi Network pour sécuriser vos transactions. Votre wallet Pi est protégé par votre propre clé privée.
